# Поездки

Планировщик поездок: перелёты, жильё и места в одном маршруте. Работает как сайт и как приложение на домашнем экране; все данные хранятся в браузере устройства.

## Публикация на GitHub Pages

1. Создай репозиторий (например, `trips`) и загрузи в него содержимое этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, папку `icons/`.
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/trips/`.
4. На телефоне: открой адрес → «Поделиться» (iPhone) или меню «⋮» (Android) → «На экран «Домой»» / «Установить приложение».

## Обновления

Правишь `index.html`, коммитишь — Pages пересоберётся сам. Чтобы у пользователей обновилась офлайн-копия, меняй строку `VERSION` в `sw.js` (v1 → v2 и т.д.).

## Память

- Данные лежат в IndexedDB этого браузера (база `poezdki`). Лимит выделяет само устройство — обычно сотни мегабайт и больше; реальные цифры видны в профиле.
- Картинки слегка сжимаются при загрузке: фон поездки до 2000px, фото жилья до 600px.
- Если раньше данные были в localStorage — при первом открытии они переедут в базу автоматически.
- Данные не синхронизируются между устройствами и браузерами. Для переноса — Профиль → «Выгрузить данные» / «Загрузить данные».
- Если очистить данные сайта в браузере, всё удалится. Регулярно делай выгрузку.

## Зависимости

- Шрифт Montserrat Alternates — Google Fonts.
- Анимации — библиотека Motion (бывший Framer Motion), jsDelivr.

После первого открытия оба ресурса кэшируются сервис-воркером, и приложение работает офлайн.
